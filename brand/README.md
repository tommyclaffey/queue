# Queue brand files

The full guide (logo, colour, type, don'ts) lives in Figma: Queue file → page **🏷 Brand**.
These are the export files. Use them as they are: scale evenly and place them, nothing else.

| Folder | What | Use it for |
|---|---|---|
| `svg/` | Every logo as a vector, text outlined | Anything that takes SVG: Figma, Framer, Canva, print |
| `png/` | Transparent PNGs at 2× and 4× | Slides, docs, anywhere SVG isn't accepted |
| `app-icon/` | App icon 1024 / 512 / 192, Apple touch icon 180, favicons 32 / 16 + `favicon.ico` | Home-screen icon, browser tab, App Store later |
| `social/` | Profile picture 1080, link preview 1200×630, header 1500×500 | Instagram/TikTok/X profile, link previews, X/LinkedIn header |

## The mark
A play button in a square with one sharp corner (bottom right): the tail of a Q. The square corner is what keeps it from reading as a video player logo, so never round it off.
The app icon puts the mark on a full-bleed colour (ink mark on lime, or lime mark on ink), because iOS and macOS round the icon's outer corners.

## Which logo *(Tommy, Oct 12, confirmed with a preview)*
**The lime Q is the logo:** the lime mark with a black play button. It's the same on every background; only the lettering changes.
- **Primary** (`queue-lockup-primary`): lime Q, black lettering. Light and white backgrounds.
- **Primary · paper** (`queue-lockup-primary-paper`): lime Q, white lettering. Dark and black backgrounds, and photos with a dark overlay.
- **Icon** (`queue-icon`, `queue-mark-lime`): the lime Q on its own. Favicons use it on a transparent background.
- **App icon** (`app-icon/`): the lime Q on full-bleed black, because iOS and macOS need a full square to round.
- **Ink and Paper** (`*-ink`, `*-paper`): one-colour versions, only when colour isn't possible (embossing, single-colour print, watermarks).
- The play button stays black on lime (13.1 : 1). White on lime would be about 1.4 : 1.

## Rules in one line each
- Clear space: half the mark's height on every side.
- Minimum size: logo 120 px wide, mark 16 px.
- Wordmark size: the capital Q is exactly as tall as the mark (Geist SemiBold at 1.41× the mark height). Its top and baseline line up with the mark's top and bottom edges.
- Never stretch, recolour, rotate, add effects, rearrange or retype it.

## Colours
Ink `#1D1D1F` · Paper `#FFFFFF` · Mist `#F5F5F7` · Black `#000000` · Lime `#C6F432` (accent) · Blue `#0066CC` (links; `#0A84FF` on dark)

## Type
Geist SemiBold (headings) · Geist Regular (body) · Geist Mono Medium, caps (labels, times, numbers). Free from Vercel: vercel.com/font

The tagline on the social images ("Post on time. Keep the quality.") is a placeholder. Swap it for the marketing site's line if that changes.
